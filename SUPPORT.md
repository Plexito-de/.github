# Getting help

- **A question about how to use a project:** open a discussion in that repository, if it has
  Discussions, or an issue with the question label.
- **A bug:** open an issue in that repository and follow its template.
- **A security problem:** follow the [security policy](SECURITY.md). Do not open a public issue.
- **Commercial work with Plexito:** [plexito.de](https://plexito.de) or
  [info@plexito.de](mailto:info@plexito.de).
